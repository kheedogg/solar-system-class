# 🪐 태양계 학습 페이지 — 기능 로드맵 (Feature Roadmap)

수업에 활용하기 위해 **구현하고 싶은 추가 기능**을 정리한 문서입니다.
구현이 완료된 내역은 [`docs/history/`](./history/) 에 날짜별로 기록합니다.

- **대상:** 초등학생 (저학년 중심)
- **언어:** 영어 + 한국어 병기 (Bilingual)
- **원칙:** 외부 라이브러리 없이 순수 HTML/CSS/JS, GitHub Pages 무료 호스팅 유지
- **유의:** 크기·거리·별자리 위치는 학습용으로 단순화 (실제와 다름)

## 상태 표기 (Legend)
| 표기 | 의미 |
|------|------|
| ✅ 완료 | 구현 후 배포됨 |
| ↩️ 롤백됨 | 구현했으나 현재 라이브에서 내려간 상태 (재도입 예정) |
| 🔜 예정 | 구현하기로 한 기능 |
| 💡 아이디어 | 검토 중인 신규 아이디어 |

---

## 1. 화면(뷰) 추가
페이지를 단일 화면에서 **여러 화면을 오가는 수업 도구**로 확장합니다. (상단 메뉴로 전환)

| 기능 | 설명 | 우선순위 | 상태 |
|------|------|:------:|:----:|
| 지구에서 보기 (Sky from Earth) | 낮→밤 슬라이더로 해가 뜨고 지고, 밤에 달·별이 뜨는 모습. "해가 아니라 지구가 돈다" 설명 포함 | 높음 | ↩️ 롤백됨 |
| 별자리 (Constellations) | 유명한 별자리(북두칠성·카시오페아·오리온·사자자리). 클릭 시 찾는 법 설명 | 높음 | ↩️ 롤백됨 |
| 인쇄용 학습지 (Worksheet) | 행성별 설명 카드 + 그림 칸이 있는 흑백 핸드아웃 (`@media print`) | 중간 | ↩️ 롤백됨 |

## 2. 인터랙션 / 조작
| 기능 | 설명 | 우선순위 | 상태 |
|------|------|:------:|:----:|
| 스크롤/핀치 확대·축소 | 마우스 휠·터치로 태양계를 확대/축소, 초기화 버튼 | 높음 | ↩️ 롤백됨 |
| 실제 크기·거리 비교 토글 | "보기 쉬운" 배치 ↔ "실제 비율(근사)" 배치 전환 + 설명 문구 | 중간 | ↩️ 롤백됨 |
| 별똥별 애니메이션 | 배경에 가끔 별똥별이 지나가는 효과 | 낮음 | ↩️ 롤백됨 |
| 공전 일시정지/재생 | 애니메이션을 멈추고 설명 (현재 라이브 v1에 포함) | — | ✅ 완료 |

## 3. 천체 추가
| 기능 | 설명 | 우선순위 | 상태 |
|------|------|:------:|:----:|
| 달 (Moon) | 지구를 도는 작은 위성, 클릭 시 설명 | 중간 | ↩️ 롤백됨 |
| 명왕성 (Pluto) | 왜소행성으로 표기, 점선 궤도 | 낮음 | ↩️ 롤백됨 |
| 소행성대 (Asteroid Belt) | 화성–목성 사이 점들의 띠 | 낮음 | ↩️ 롤백됨 |
| 혜성 (Comet) | 꼬리가 있는 천체, 별도 궤도 | 낮음 | ↩️ 롤백됨 |

## 4. 신규 아이디어 (미구현)
| 기능 | 설명 | 우선순위 | 상태 |
|------|------|:------:|:----:|
| 퀴즈 게임 (Quiz) | 객관식 문제 + 점수. 수업 마무리 활동에 적합 | 높음 | 💡 아이디어 |
| 소리내어 읽기 (TTS) | 행성 이름·설명을 영어/한국어로 읽어주기 (Web Speech API) | 높음 | 💡 아이디어 |
| 행성 순서 맞히기 | 태양에서 가까운 순서로 끌어다 놓는 게임 | 중간 | 💡 아이디어 |
| 오늘의 우주 사실 | 버튼을 누르면 랜덤 우주 사실(영/한) 표시 | 낮음 | 💡 아이디어 |
| 계절별/황도 12궁 별자리 | 봄·여름·가을·겨울 또는 12궁 별자리 추가 | 낮음 | 💡 아이디어 |
