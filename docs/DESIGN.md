# 🎨 디자인 & 개발 설계 (Design & Build Plan)

> 웹 기획자 · 풀스택 개발자 · UI/UX 디자이너 3자 논의를 종합한 문서입니다.
> **원칙:** 기능은 가볍게, 화면은 **촌스럽지 않고 매우 고퀄리티**로. **인터랙션 최우선.**
> 대상: 초등 저학년 · 영어/한국어 병기 · 순수 HTML/CSS/JS · GitHub Pages.
>
> 작성일: 2026-06-11

---

## 1. 논의 요약 (3자 합의 사항)

### 🧭 기획자 (Product)
- **지금은 적은 수의 기능을 "완성도 높게"** 가는 게 핵심. 기능 나열이 아니라 *아이가 만지고 반응을 얻는 루프*가 중요.
- 추천 우선순위: **퀴즈(완료) → 소리내어 읽기(TTS) → 멀티뷰 전환 → 행성 순서 맞히기 드래그**.
- "높은 인터랙션 품질"의 성공 기준: ① 누르면 0.2초 안에 시각/청각 반응이 온다 ② 정답·오답에 *기분 좋은* 피드백이 있다 ③ 글을 못 읽는 아이도 아이콘·소리만으로 사용 가능.

### 🛠️ 개발자 (Architecture)
- 빌드 도구·라이브러리 없이 정적 파일 유지. 단, `script.js` 단일 파일이 비대해지므로 **멀티뷰부터는 ES 모듈로 분리**.
  - `js/data.js`(공유 데이터) · `js/app.js`(~30줄 해시 라우터 `#solar`,`#quiz`) · `js/views/*.js`(뷰별 mount/unmount).
- 모든 기능은 **하나의 `PLANETS` 데이터**를 공유 (퀴즈·TTS·드래그가 같은 소스 사용).
- **드래그는 Pointer Events**로 (HTML Drag&Drop API는 아이패드에서 동작 안 함). 터치 타깃 최소 **44px**.
- **TTS는 `ko-KR` 음성이 일부 기기에 없음** → 영어 우선/한국어는 가능할 때만, *graceful fallback*.
- 비주얼은 **CSS-only**(radial/conic-gradient, box-shadow glow, backdrop-filter glass)로 충분히 고퀄 달성 가능. 이미지/canvas 불필요.
- 뷰 전환 타이머 누수 주의(과거 v2의 sky setInterval 버그) → unmount 시 정리.

### ✨ 디자이너 (UI/UX) — "촌스럽지 않게" 가드레일
- **액센트 색은 1계열만.** 무지개 그라데이션·원색 남발 금지.
- **이모지는 art가 아니라 accent로** 소량만. 코믹/만화 폰트 금지(→ 둥글지만 정제된 **Jua** 채택, *적용 완료*).
- 정답 피드백은 *부드러운 glow/별 반짝임*, 색종이 폭죽(confetti) 떡칠 금지.
- 깊은 우주 톤 유지 + 유리질(glassmorphism) 패널, 절제된 그림자/광. **여백 리듬(4/8px)**·**일관된 radius 스케일**로 "프리미엄" 느낌.

## 2. 비주얼 언어 (Design Tokens)

기존 팔레트를 **절제해서 확장**합니다. (현 `:root` 기반)

| 토큰 | 값 | 용도 |
|------|-----|------|
| `--bg-deep` / `--bg-mid` | `#05060f` / `#0d1030` | 우주 배경 |
| `--text` | `#f4f6ff` | 본문(영어) |
| `--text-ko` | `#b9e0ff` | 한국어 병기 |
| `--accent` | `#ffd54a` | **단일 액센트**(태양/강조) |
| `--accent-soft` | `rgba(255,213,74,.18)` | hover·선택 배경 |
| `--correct` | `#7be3a0` | 정답 |
| `--wrong` | `#ff9aa6` | 오답(부드럽게) |
| `--panel` | `rgba(16,20,48,.72)` + `backdrop-filter: blur(14px)` | 유리 패널 |

- **폰트:** `Jua`(둥근 친근체) → fallback 시스템 스택. *(적용 완료)*
- **Radius 스케일:** 8 / 14 / 20 / 999(pill).
- **그림자/광:** elevation 1 `0 6px 20px rgba(0,0,0,.35)`, 시그니처 glow `0 0 24px var(--accent-soft)`.
- **이징:** 표준 `cubic-bezier(.22,.61,.36,1)`(부드러운 감속), 통통 `cubic-bezier(.34,1.56,.64,1)`(정답·등장).
- **모션 시간:** hover 120ms · press 90ms · 패널 등장 220ms · 뷰 전환 260ms.

## 3. 인터랙션 스펙 (Micro-interactions)

- **버튼/행성 press:** `transform: scale(.94)` 90ms → 복귀. 행성 hover 시 살짝 떠오름 + 외곽 glow.
- **뷰 전환:** 나가는 화면 fade+소폭 축소, 들어오는 화면 fade+상승(translateY 8px→0), 260ms.
- **퀴즈 정답:** 카드 초록 테두리 + 별(⭐) 1개 톡 튀어오르고 점수 카운트업. *부드러운 glow 1회*.
- **퀴즈 오답:** 카드 좌우 미세 shake(120ms) + 정답 살짝 하이라이트, 비난 없는 톤("다시 해볼까? · Try again!").
- **드래그:** 집을 때 chip 살짝 확대+그림자 상승, 올바른 슬롯 근처에서 슬롯이 *숨 쉬듯* 빛남, 놓으면 통통 정착.
- **TTS 재생 중:** 스피커 아이콘 맥동(pulse) + 해당 텍스트 라인 하이라이트.

## 4. 화면/네비게이션 설계

```
┌───────────────────────────────────────────┐
│            🪐 The Solar System  태양계        │   ← 헤더(타이틀 + 일시정지)
│   [🪐 태양계] [⭐ 별자리] [🌅 지구에서]  ← 멀티뷰 탭(추후)
├───────────────────────────────────────────┤
│                                             │
│                  ☀️  (행성 공전)             │   ← 메인 뷰
│                                             │
│                                  🚀 ← FAB    │   ← 우하단 게임 메뉴(완료)
└───────────────────────────────────────────┘
```
- 멀티뷰 탭: 큰 터치 타깃(≥44px), pill 형태, 활성 탭은 `--accent` 밑줄+밝기. 영/한 병기.
- 게임은 FAB(🚀)로 진입 → 퀴즈/순서맞히기. 메인 학습 화면을 어지럽히지 않음.

## 5. 개발 로드맵 (Phase별)

| Phase | 기능 | 상태 | 난이도 | 비고 |
|:--:|------|:--:|:--:|------|
| 1 | v1 태양계 + 클릭 설명 + 일시정지 | ✅ | — | 라이브 |
| 1.5 | **모든 행성 클릭 버그 수정 + Jua 폰트** | ✅ | S | 본 세션 |
| 2 | 퀴즈 게임(FAB) | ✅ | M | 디자인 토큰 재정비 예정 |
| 3 | **소리내어 읽기(TTS)** | ✅ | S | 설명 팝업·퀴즈에 🔊, EN→KO 순차, ko-KR fallback, 맥동 표시 (음성 청취 검증만 남음) |
| 4 | **멀티뷰 전환 + 별자리/지구에서 보기 복구** | 🔜 | M | v2.0.0 자산 참고, ES 모듈화 시작 |
| 5 | **행성 순서 맞히기(드래그)** | 🔜 | M | Pointer Events |
| 6 | 부가: 달/명왕성/혜성, 별똥별, 학습지 | 💡 | S~M | 여유 시 |

### 다음 단계(Phase 3 — TTS) 구체안
1. `script.js`에 `speak(text, lang)` 헬퍼 추가 — `speechSynthesis`, `voiceschanged`로 음성 비동기 로딩 처리.
2. `ko-KR` 음성 없으면 영어만 읽고 UI에 조용히 안내(에러 없음).
3. 설명 팝업의 각 fact 줄과 행성 이름 옆에 **🔊 버튼**(44px) 추가, 재생 중 맥동.
4. 사용자 제스처(클릭) 이후에만 호출 → autoplay 정책 회피.

### Phase 4부터의 구조 전환
```
index.html
js/
 ├─ data.js     (PLANETS, SUN, QUIZ 등 공유 데이터)
 ├─ app.js      (해시 라우터 + 뷰 mount/unmount)
 └─ views/  solar.js · quiz.js · constellations.js · sky.js
styles/  (뷰별 분리 또는 단일 유지)
```
> 전환은 **Phase 4 진입 시점에 한 번**만. 그 전까지는 현 단일 파일 유지(과한 선반영 금지).

## 6. 품질 검증
- `node --check script.js` (문법) · JS가 참조하는 모든 element ID가 HTML에 존재하는지 확인.
- 헤드리스/실제 브라우저에서 콘솔 에러 0, 동적 생성 요소 렌더 확인.
- 터치(아이패드) 클릭·드래그, `prefers-reduced-motion`, 키보드 포커스·ESC 닫기 점검.
- 모든 텍스트 영/한 병기 및 명도 대비 확인.
