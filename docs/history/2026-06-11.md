## ② v2.0.0 — 4개 화면 수업 도구로 확장 ✅(후에 롤백)
선생님 요청으로 단일 화면을 **여러 화면을 오가는 수업 도구**로 확장.

**상단 메뉴(뷰 전환) 추가 — 4개 화면**
1. **🪐 태양계** — 기존 화면 + 아래 기능 추가
   - 스크롤/핀치 **확대·축소** + 초기화
   - **실제 크기·거리 비교** 토글
   - 천체 추가: **달, 명왕성, 소행성대, 혜성** (모두 클릭 가능)
   - 행성 시작 위치를 궤도에 골고루 분산
   - 배경 **별똥별** 효과
2. **🌅 지구에서 보기** — 낮→밤 슬라이더, 해·달이 하늘을 가로지름
3. **⭐ 별자리** — 북두칠성·카시오페아·오리온·사자자리, 클릭 시 설명
4. **🖨️ 학습지(인쇄)** — 행성별 카드 + 그림 칸, 인쇄용 레이아웃

**공통**
- 모든 천체/별자리 클릭 시 영어/한국어 설명 (기존 `openDetails` 재사용)
- "그림은 학습용, 실제 크기·거리와 다름" 안내 문구 추가

**검증**
- `node --check` 통과, JS가 참조하는 모든 element ID가 HTML에 존재함을 확인
- 헤드리스 Chrome 렌더링으로 JS 오류 없음 + 동적 생성 요소(궤도·별자리 SVG·학습지 카드) 확인
- 스크린샷으로 태양계 화면 레이아웃 확인

**릴리스 및 정리**
- 릴리스 **v2.0.0 — Sky & Constellations** 생성
- 실수로 커밋된 도구 상태 파일(`.omc/`) 제거 및 `.gitignore`에 추가

**대표 커밋:** `e802365` (Expand into 4-view class tool), `1054b6e` (.omc 정리)
